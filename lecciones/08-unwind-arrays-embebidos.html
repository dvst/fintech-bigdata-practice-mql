$unwind y arrays embebidos

En este dataset cada factura contiene arrays de visualizaciones. Para contar, agrupar u ordenar visualizaciones (no facturas) hay que desplegar esos arrays: $unwind convierte cada elemento en un documento propio.

  • Desplegar un array con $unwind y combinarlo con $group
  • Desplegar arrays anidados (Movies → Genres)
  • Controlar qué pasa con los documentos sin array
  • Elegir la granularidad correcta: factura, visualización o título
① Concepto

Un documento por elemento

Recórrelo con tres facturas de ejemplo (géneros simplificados). Observa qué le pasa a la factura de Portugal, que no tiene Movies:

② Sintaxis

Formas de $unwind

mongosh
{ $unwind: "$Movies" }                         // forma corta

{ $unwind: {
    path: "$Movies",
    preserveNullAndEmptyArrays: true,          // conserva facturas sin Movies (Movies queda ausente)
    includeArrayIndex: "posicion"              // añade la posición del elemento (0, 1, 2…)
} }
Documento de entrada$unwind normalcon preserveNullAndEmptyArrays

Desaparecer también es un resultado

Si cuentas «facturas por país» después de $unwind: "$Movies", las facturas sin películas ya no están, y además cada factura cuenta tantas veces como películas tenga. Decide qué necesitas antes de desplegar.

③ Granularidad

¿Qué es una «fila» en tu resultado?

Antes de escribir un pipeline, pregúntate qué representa cada documento en cada punto:

Tras…Cada documento es…Cuántos hay
la collectionuna factura (cliente × mes)una por cliente y mes
$unwind: "$Movies"una visualización de una películavarias por factura (y ninguna de las facturas sin películas)
$unwind: "$Series"una visualización de un episodiovarias por factura
$unwind + $group por títulouna película del catálogouna por título distinto
La misma película aparece muchas veces

Cada visualización trae copiados los Details de la película (duración, idioma, géneros…). Si haces una media de duraciones después de $unwind, las películas muy vistas pesan más. Si lo que quieres es el catálogo, agrupa antes por título para tener una fila por película.

④ Rendimiento

Desplegar con cabeza

  • $match antes de $unwind siempre que puedas filtrar por campos de la factura: desplegas menos.
  • $match justo después si el filtro es sobre los elementos ("Movies.Viewing PCT"): reduce la cantidad que llega a $group.
  • Si solo necesitas contar o filtrar elementos dentro de cada factura, no hace falta desplegar: $size y $filter (lección 09) trabajan dentro del documento.
  • Para volver a juntar lo desplegado: { $group: { _id: "$_id", Movies: { $push: "$Movies" } } }.
⑤ Chuleta

Resumen

Quiero…Escribo
una fila por elemento{ $unwind: "$arr" }
conservar documentos sin array{ $unwind: { path: "$arr", preserveNullAndEmptyArrays: true } }
arrays dentro de arraysdos $unwind: "$Movies" y luego "$Movies.Details.Genres"
contar elementos por valor$unwind → $group: { _id: "$arr.x", n: { $sum: 1 } }
ranking estable{ $sort: { n: -1, _id: 1 } }
reconstruir$group por _id + $push
