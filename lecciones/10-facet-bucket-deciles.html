$facet, $bucket y deciles

Dos herramientas para informes: $facet calcula varios resultados a la vez sobre la misma entrada, y $bucket / $bucketAuto reparten los documentos en tramos. Con ellas, y con las funciones de ventana, se calculan percentiles y deciles.

  • Devolver varias listas en una sola consulta con $facet
  • Repartir en tramos fijos ($bucket) o equilibrados ($bucketAuto)
  • Calcular el decil de cada documento con $setWindowFields
  • Decidir y documentar: ¿deciles de qué?, ¿qué pasa con los empates?
① Concepto

$facet: varias consultas en una

mongosh
db.__COL__.aggregate([
  { $match: { billing: "March 2025" } },          // las etapas previas son comunes
  { $facet: {
      porTipo: [ { $group: { _id: "$contract.product.type", n: { $sum: 1 } } }, { $sort: { _id: 1 } } ],
      top3:    [ { $group: { _id: "$contract.country", n: { $sum: 1 } } }, { $sort: { n: -1, _id: 1 } }, { $limit: 3 } ]
  } }
])
Límites de $facet

El resultado es un único documento, que no puede superar 16 MB: no metas listas enormes. Dentro de una rama no puedes usar $facet, $out ni $merge. Si luego quieres procesar cada lista, usa $project / $unwind sobre sus arrays.

③ Deciles

¿En qué decil está cada documento?

Un decil divide los valores ordenados en 10 grupos con el mismo número de elementos: el decil 1 es el 10 % más bajo y el 10, el 10 % más alto. Hay varias formas de calcularlo en MongoDB:

MétodoIdeaOjo con
$bucketAuto con buckets: 10te da los 10 tramos y sus límitespuede salir con menos tramos o tamaños desiguales si hay muchos empates
$setWindowFields + $rankposición de cada documento en el orden → decil = ⌈10 · posición / total⌉los empates comparten posición (resultado determinista)
$percentile (MongoDB 7.0+)calcula el valor del percentil 10, 90… y luego filtrasen 7.x solo existe el método approximate
Dos consultasprimero calculas el umbral, luego filtras con élmenos elegante, pero muy fácil de documentar y comprobar
mongosh
db.__COL__.aggregate([
  // 1) población: las facturas con importe numérico (sin dato no hay decil)
  { $match: { TOTAL: { $type: "number" } } },
  // 2) posición y total
  { $setWindowFields: {
      sortBy: { TOTAL: 1 },
      output: {
        pos:   { $rank: {} },
        total: { $count: {}, window: { documents: ["unbounded", "unbounded"] } }
      }
  } },
  // 3) decil
  { $set: { decil: { $ceil: { $multiply: [10, { $divide: ["$pos", "$total"] }] } } } }
])
Decisiones que debes documentar

Antes de calcular un decil responde, y déjalo escrito: ¿deciles de qué población? (todas las facturas, un mes, un país…), ¿qué haces con los documentos sin el dato?, ¿cómo tratas los empates? y ¿qué método usas? Dos métodos razonables pueden dar listas ligeramente distintas en los bordes: explicar por qué es parte de un buen análisis.
