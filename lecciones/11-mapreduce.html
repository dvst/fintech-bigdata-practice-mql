MapReduce

MapReduce es el modelo clásico de procesamiento distribuido: una función map emite pares clave → valor y una función reduce combina los valores de cada clave. En MongoDB está obsoleto desde la versión 5.0 (se recomienda el pipeline), pero sigue funcionando y conviene conocerlo: aparece en muchos sistemas heredados y es la base del procesamiento distribuido.

  • Entender las fases map → shuffle → reduce → finalize
  • Escribir map, reduce y finalize correctos
  • Respetar las reglas de reduce (y por qué las medias van en finalize)
  • Usar query, out y traducir a aggregation

En este laboratorio

Para proteger tus datos, la terminal del tutorial solo permite out: { inline: 1 } o escribir en la database de prácticas: out: { replace: "nombre", db: "__SANDBOX__" }. En tu mongosh normal puedes usar cualquier opción.

No uses funciones flecha en map

En () => emit(this.billing, 1), this no es el documento. Usa siempre function () { … } en map. Dentro de forEach sí puedes usar flechas, porque ahí no necesitas this.

③ Reglas de reduce

Por qué la media no va en reduce

MongoDB puede llamar a reduce varias veces para la misma clave (con resultados parciales de llamadas anteriores mezclados con valores nuevos) y no la llama cuando una clave tiene un solo valor. Por eso reduce debe cumplir:

ReglaSignifica
Mismo tipodevuelve un valor con la misma forma que los que emite map
Asociativa y conmutativael orden de los valores y cómo se agrupen no cambia el resultado
Idempotentereduce(k, [reduce(k, vs)]) = reduce(k, vs)
mongosh
// ✗ MAL: la media de medias no es la media, y con un solo valor ni se ejecuta
function (k, vs) { return Array.avg(vs); }

// ✓ BIEN: reduce acumula suma y recuento; finalize divide al final
map      = function ()      { emit(this.billing, { total: this.TOTAL, n: 1 }); }
reduce   = function (k, vs) { var r = { total: 0, n: 0 };
                              vs.forEach(function (v) { r.total += v.total; r.n += v.n; });
                              return r; }
finalize = function (k, v)  { v.media = v.total / v.n; return v; }
④ Patrones

Cosas que conviene saber

  • Recorrer arrays en map: (this.Movies || []).forEach(function (m) { emit(…); }). El || [] evita el error en documentos sin array.
  • Claves compuestas: emit({ pais: this.contract.country, mes: this.billing }, …).
  • Clave ausente: si emites undefined, se agrupa como null. Decide si quieres excluirla (con un if en map).
  • Varias métricas a la vez: emite un objeto con un campo por métrica y súmalos todos en reduce.
  • query filtra antes de map (más eficiente que un if dentro de map).
  • scope pasa variables a las funciones: scope: { umbral: 50 }.
