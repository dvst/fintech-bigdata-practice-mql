$group y acumuladores

$group convierte muchos documentos en uno por cada valor de una clave, y calcula sobre cada grupo sumas, medias, máximos, listas… Es el GROUP BY de MongoDB y el corazón de casi cualquier análisis.

  • Agrupar por un campo, por varios o por toda la collection
  • Usar los acumuladores: $sum, $avg, $min, $max, $push, $addToSet, $first
  • Contar valores distintos
  • Aplicar el patrón «el más frecuente de cada grupo»
① Concepto

De muchos documentos a uno por grupo

El orden de los elementos de $addToSet no está garantizado.

② Anatomía

La etapa $group

mongosh
{ $group: {
    _id: <clave>,                       // obligatorio: por qué se agrupa
    <campo>: { <acumulador>: <expresión> },
    …
} }
Clave (_id)Grupos
"$contract.country"uno por país
{ pais: "$contract.country", mes: "$billing" }uno por cada combinación país + mes (clave compuesta)
nulluno solo con toda la collection (totales globales)
AcumuladorCalcula
{ $sum: 1 }número de documentos del grupo
{ $sum: "$TOTAL" }suma de un campo
{ $avg: "$TOTAL" }media (ignora los documentos sin ese campo)
$min · $maxmínimo · máximo
{ $push: "$x" }array con todos los valores (con repetidos)
{ $addToSet: "$x" }array de valores distintos
$first · $lastel valor del primer / último documento del grupo (según el orden de entrada: ordena antes)
{ $top: { sortBy: {…}, output: … } }el primero según un orden propio (MongoDB 5.2+)
Tras $group solo queda lo que calculas

La salida de $group tiene únicamente _id y los acumuladores. Si después necesitas el nombre del cliente, inclúyelo en la clave o recógelo con un acumulador ($first). Y con clave compuesta, sus partes se leen como "$_id.pais".

③ Recetas

Patrones que vas a reutilizar

Totales globales

mongosh
{ $group: { _id: null, facturas: { $sum: 1 }, ingresos: { $sum: "$TOTAL" } } }

Contar valores distintos

mongosh
{ $group: { _id: "$contract.country", clientes: { $addToSet: "$Client.customer code" } } },
{ $project: { clientes: { $size: "$clientes" } } }
Un cliente, varias facturas

Cada cliente aparece una vez por mes facturado. Si cuentas facturas, cuentas meses; si quieres clientes, cuenta valores distintos de un identificador del cliente (customer code o DNI).

Contar y ordenar en un paso

mongosh
{ $sortByCount: "$contract.product.Reference" }
// equivale a: { $group: { _id: "$…", count: { $sum: 1 } } }, { $sort: { count: -1 } }

El más frecuente de cada grupo

mongosh
db.__COL__.aggregate([
  { $group: { _id: { pais: "$contract.country", tarifa: "$contract.product.Reference" }, n: { $sum: 1 } } },
  { $sort: { "_id.pais": 1, n: -1, "_id.tarifa": 1 } },
  { $group: { _id: "$_id.pais", tarifa: { $first: "$_id.tarifa" }, n: { $first: "$n" } } }
])

Con MongoDB 5.2 o superior, el segundo y tercer paso caben en uno: { $group: { _id: "$_id.pais", top: { $top: { sortBy: { n: -1, "_id.tarifa": 1 }, output: ["$_id.tarifa", "$n"] } } } }.
