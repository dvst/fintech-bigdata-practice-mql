Arrays y subdocumentos

En este dataset lo interesante vive dentro de arrays: Movies, Series, Genres, Keywords, Stars… Consultar arrays tiene reglas propias, y la más traicionera es que varias condiciones sobre un array no tienen por qué cumplirse en el mismo elemento.

  • Buscar por elementos de un array y por arrays de subdocumentos
  • Contar elementos: $size y el truco del índice
  • Exigir varias condiciones al mismo elemento con $elemMatch
  • Proyectar partes de un array
① Concepto

¿El mismo elemento o cualquiera?

Compruébalo tú: en este playground están las 8 facturas de ejemplo con sus películas (simplificadas: aquí los géneros están en Movies.Genres; en tu collection están en Movies.Details.Genres).

② Buscar en arrays

Reglas básicas

FiltroCoincide cuando…
{ "Series.Title": "Six Roommates" }algún elemento de Series tiene ese Title
{ "Movies.Details.Genres": "Drama" }algún género de alguna película es Drama (arrays dentro de arrays se «aplanan»)
{ "Movies.Viewing PCT": { $lt: 10 } }alguna película se vio menos del 10 %
{ arr: ["a", "b"] }el array es exactamente ["a", "b"] (mismo orden), o contiene ese array como elemento
{ arr: { $all: ["a", "b"] } }contiene a y b, en cualquier orden y posición
{ arr: { $in: ["a", "b"] } }contiene a o b
③ Tamaño y posición

Contar elementos

mongosh
{ Series: { $size: 3 } }               // exactamente 3 series
{ Series: { $size: 0 } }               // array vacío (no coincide si Series no existe)
{ "Movies.4": { $exists: true } }      // existe el 5.º elemento → 5 o más películas
{ "Movies.4": { $exists: false } }     // menos de 5 (incluye facturas sin Movies)
{ "Movies.0.Title": "Dawn Banners" }    // la primera película es Dawn Banners
$size no admite rangos

{ $size: { $gt: 3 } } da error. Para «al menos N» usa el índice N-1 con $exists; para comparaciones más complejas, $expr con el operador de agregación $size (lección 09).

Campos que unas veces son array y otras no

En una collection sin esquema, un campo puede ser un array en unos documentos y un valor simple en otros. $size y los índices posicionales solo coinciden con arrays; { campo: { $type: "array" } } te dice cuáles lo son. Comprueba siempre el tipo antes de decidir (receta de la lección 01).

④ $elemMatch

Varias condiciones sobre el mismo elemento

mongosh
// alguna película que sea Drama Y se viera menos del 10 % (la misma)
db.__COL__.find({
  Movies: { $elemMatch: { "Details.Genres": "Drama", "Viewing PCT": { $lt: 10 } } }
})

// alguna película que tenga a la vez los géneros Action y Comedy
db.__COL__.find({
  Movies: { $elemMatch: { "Details.Genres": { $all: ["Action", "Comedy"] } } }
})
¿Cuándo hace falta?

Solo cuando hay dos o más condiciones sobre campos de los elementos de un mismo array y deben cumplirse juntas. Con una sola condición, "Movies.X": … y $elemMatch dan lo mismo.

⑤ Proyectar arrays

Devolver solo parte de un array

ProyecciónDevuelve
{ "Movies.Title": 1 }el array Movies con solo el Title de cada película
{ Movies: { $slice: 2 } }las 2 primeras películas (y el resto de campos del documento)
{ Movies: { $slice: -1 } }la última película
{ Movies: { $elemMatch: { "Viewing PCT": { $lt: 10 } } } }solo la primera película que cumple la condición
find({ "Movies.Title": "Titanic" }, { "Movies.$": 1 })solo el elemento que hizo coincidir el filtro (operador posicional $)
