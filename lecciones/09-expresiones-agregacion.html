Expresiones de agregación

Las expresiones son fórmulas que se evalúan sobre cada documento: aritmética, condiciones, operaciones con arrays y textos, conversiones de tipo… Con ellas se comparan dos campos del mismo documento, algo que un filtro normal no puede hacer.

  • Distinguir operadores de consulta y expresiones
  • Comparar campos entre sí con $expr
  • Clasificar con $cond y $switch y protegerte de ausencias con $ifNull
  • Operar dentro de arrays sin desplegarlos: $size, $filter, $map, $in
① Concepto

Dos sintaxis que se parecen (y no son iguales)

Las expresiones viven en $project, $addFields, $group (dentro de acumuladores) y, envueltas en $expr, en $match. Recorre este ejemplo:

② $expr

Comparar campos del mismo documento

mongosh
// ¿episodio visto = último episodio de la temporada?
db.__COL__.aggregate([
  { $unwind: "$Series" },
  { $match: { $expr: { $eq: ["$Series.Episode", "$Series.Total Episodes"] } } }
])

// también funciona en find()
db.__COL__.find({ $expr: { $gt: ["$TOTAL", "$contract.product.monthly fee"] } })
Qué campos puede usar una expresión

Cualquiera del documento que llega a la etapa, incluidos los de subdocumentos ("$contract.product.type"). Dentro de $filter o $map, cada elemento del array se nombra con una variable ("$$m.campo").

③ Condiciones

$cond, $switch e $ifNull

mongosh
// dos ramas
{ $cond: [ { $gte: ["$TOTAL", 50] }, "alta", "normal" ] }

// varias ramas
{ $switch: {
    branches: [
      { case: { $gte: ["$Movies.Viewing PCT", 90] }, then: "completa" },
      { case: { $gte: ["$Movies.Viewing PCT", 50] }, then: "parcial" }
    ],
    default: "abandonada"
} }

// valor por defecto si falta (o es null)
{ $ifNull: ["$Client.Phone", "sin teléfono"] }
④ Arrays

Trabajar dentro del array

ExpresiónDevuelve
{ $size: "$Movies" }número de elementos. Error si Movies no existe: usa { $size: { $ifNull: ["$Movies", []] } }
{ $filter: { input: "$Movies", as: "m", cond: … } }los elementos que cumplen cond (dentro, "$$m.campo")
{ $map: { input: "$Movies", as: "m", in: "$$m.Title" } }un array transformado (aquí, solo títulos)
{ $in: ["Drama", "$Movies.Details.Genres"] }si un valor está en un array. Error si el segundo argumento no es un array
{ $arrayElemAt: ["$Movies", 0] }el elemento de una posición
{ $reduce: { input, initialValue, in } }un valor acumulado (sumas, concatenaciones…)
"$Movies.Title" en una expresiónel array de todos los títulos
Un error muy frecuente

MongoServerError: $in requires an array as a second argument, found: missing. En una collection sin esquema, algún documento no tiene el array. Protégete siempre: { $in: [x, { $ifNull: ["$arr", []] }] }, o filtra antes con { arr: { $type: "array" } }.

⑤ Tipos y textos

Conversiones, textos y fechas

ExpresiónPara qué
{ $toString: "$Client.Phone" }número → texto (para usar regex sobre él)
{ $regexMatch: { input: …, regex: /00$/ } }regex dentro de una expresión
$toInt, $toDouble, { $convert: { input, to, onError, onNull } }conversiones, con valor alternativo si fallan
$concat, $toLower, $split, $substrCP, $trimmanipular textos
{ $dateFromString: { dateString: "$Movies.Date", format: "%d/%m/%Y" } }las fechas del dataset son texto: así se convierten en fechas reales
$add, $subtract, $multiply, $divide, $roundaritmética (dividir entre 0 da error: protégete con $cond)
