Tutorial interactivoMongoDB Query Language

Aprende MQL con tus propios datos

Un tutorial guiado para dominar find(), el aggregation pipeline y MapReduce sobre tu propia base de datos (__DB__.__COL__). Cada concepto tiene su página: vuelve a ella siempre que la necesites.

TU PROGRESO
Cómo funciona
  1. Concepto visual. Cada lección empieza con un diagrama animado que muestra el mecanismo antes de tocar la terminal.
  2. Lab en vivo. Una terminal mongosh real conectada a tu MongoDB, sin simuladores.
  3. Validación automática. Tu consulta se ejecuta y se compara con el resultado esperado, no con el texto que escribas.
  4. Misiones. Tickets estilo Jira con criterios de aceptación, como en un trabajo real.

Puesta en marcha

Arrancar el laboratorio

Necesitas tu mongod en marcha y, en otra terminal, dentro de la carpeta mql-tutorial:

bash
node server.js

Se abre el navegador solo. El servidor localiza mongosh y el dataset automáticamente (ahora usa __DB__.__COL__). Si algo falla, node server.js --check te dice qué falta; los detalles están en README.md.
