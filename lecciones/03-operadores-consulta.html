Operadores de consulta

La igualdad no basta para casi nada. Los operadores (siempre empiezan por $) permiten rangos, listas de valores, combinaciones con OR y, sobre todo en este dataset, preguntar si un campo existe o de qué tipo es.

  • Comparar con $gt, $lte, $ne, $in…
  • Combinar condiciones con $and, $or, $nor, $not
  • Distinguir campo ausente, null y vacío
  • Filtrar por tipo con $type
① Concepto

Un operador sustituye al valor

En vez de campo: valor escribes campo: { $operador: valor }. Edita el filtro o pulsa los ejemplos:

Las 8 facturas son de ejemplo (inventadas); las películas y series se muestran solo por título.

② Comparación

Operadores de comparación

OperadorSignificaEjemplo
$eqigual (es lo que hace campo: valor){ TOTAL: { $eq: 50 } }
$nedistinto{ billing: { $ne: "January 2025" } }
$gt · $gtemayor · mayor o igual{ TOTAL: { $gt: 100 } }
$lt · $ltemenor · menor o igual{ "Movies.Viewing PCT": { $lt: 10 } }
$inestá en la lista{ billing: { $in: ["May 2025", "June 2025"] } }
$ninno está en la lista{ "contract.country": { $nin: ["Spain"] } }
Comparar tipos distintos

Las comparaciones de rango solo encajan entre valores del mismo «tipo de comparación»: { TOTAL: { $gt: "50" } } (con comillas) no devuelve nada porque "50" es texto y TOTAL es número. Y recuerda que las fechas del dataset son texto (lección 01).

③ Lógica

Combinar condiciones

mongosh
// AND implícito: varias claves en el mismo filtro
{ "contract.country": "Spain", TOTAL: { $gt: 50 } }

// $and explícito: necesario cuando repites clave (p. ej. dos $or)
{ $and: [
    { $or: [ { billing: "May 2025" }, { billing: "June 2025" } ] },
    { $or: [ { Movies: { $exists: false } }, { Series: { $exists: false } } ] }
] }

// $or: al menos una
{ $or: [ { TOTAL: { $gt: 100 } }, { "contract.country": "Japan" } ] }

// $nor: ninguna
{ $nor: [ { Movies: { $exists: true } }, { Series: { $exists: true } } ] }

// $not: niega el operador de UN campo
{ TOTAL: { $not: { $gt: 50 } } }   // ≤ 50 o sin TOTAL
Error clásico: clave repetida

En un objeto JavaScript una clave repetida sustituye a la anterior: { TOTAL: { $gt: 10 }, TOTAL: { $lt: 20 } } se queda solo con $lt: 20, sin avisar. Escribe { TOTAL: { $gt: 10, $lt: 20 } } o usa $and.

④ Ausencias

Campo ausente, null, vacío

Como no todas las facturas tienen los mismos campos, este cuadro es de los más útiles del tutorial:

FiltroCoincide si el campo…
{ f: { $exists: false } }no existe
{ f: { $exists: true } }existe (con cualquier valor, incluido null)
{ f: null }vale null o no existe
{ f: { $type: "null" } }vale null (y existe)
{ f: { $ne: null } }existe y no es null
{ f: { $type: "array" } }es un array
{ f: { $size: 0 } }es un array vacío (lección 04)
{ f: { $ne: "x" } }vale otra cosa o no existe

$type acepta alias: "string", "int", "long", "double", "number" (cualquiera de los numéricos), "object", "array", "bool", "null", "date". Y una lista: { $type: ["int", "double"] }.

⑤ Chuleta

Resumen

Quiero…Escribo
un rango{ x: { $gte: a, $lt: b } }
uno de varios valores{ x: { $in: [a, b, c] } }
A o B{ $or: [ {A}, {B} ] }
ni A ni B{ $nor: [ {A}, {B} ] }
negar un operador{ x: { $not: { $gt: 5 } } }
que el campo exista / no exista{ x: { $exists: true | false } }
un tipo concreto{ x: { $type: "array" } }
