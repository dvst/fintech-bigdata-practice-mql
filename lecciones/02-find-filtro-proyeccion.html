find(): filtro y proyección

find() es la consulta básica de MongoDB. Responde a tres preguntas: qué documentos (filtro), qué campos (proyección) y en qué orden y cuántos (modificadores del cursor).

  • Escribir filtros de igualdad, también sobre campos anidados
  • Combinar varias condiciones (AND implícito)
  • Proyectar solo los campos necesarios
  • Ordenar, paginar y limitar resultados
① Concepto

Anatomía de una consulta

Pulsa las etapas para ver qué le pasa a cada documento. Son 8 facturas de ejemplo (inventadas, con la misma estructura que las de tu dataset), recortadas para que quepan:

Aunque escribas .limit(2).sort(…), el servidor aplica siempre el mismo orden: filtro → sort → skip → limit → proyección.

② Filtro

Filtrar por igualdad

El filtro es un documento con pares campo: valor. Un documento pasa si todos los pares se cumplen (AND implícito):

mongosh
// una condición
db.__COL__.find({ billing: "March 2025" })

// dos condiciones (AND): marzo Y España
db.__COL__.find({ billing: "March 2025", "contract.country": "Spain" })

// campo anidado: notación de puntos entre comillas
db.__COL__.find({ "contract.product.Reference": "Free Rider" })

// campo con espacios: también entre comillas
db.__COL__.find({ "contract.product.monthly fee": 10 })
Igualdad sobre arrays

Si la ruta pasa por un array, la igualdad se cumple cuando algún elemento coincide: { "Movies.Title": "Titanic" } encuentra las facturas en las que, entre todas las películas vistas, hay una llamada Titanic.

Igualdad exacta

"Spain" no es "spain" ni "Spain ". Y un subdocumento completo solo es igual si coinciden todos sus campos en el mismo orden: por eso casi siempre se filtra por campos concretos con puntos, no por subdocumentos enteros.

③ Proyección

Elegir los campos

El segundo argumento indica qué campos devolver. Hay dos modos, que no se pueden mezclar:

ModoEjemploResultado
Inclusión (1){ "Client.Name": 1, TOTAL: 1 }Solo esos campos y _id (que va incluido por defecto).
Exclusión (0){ Movies: 0, Series: 0 }Todo menos esos campos.
Única mezcla válida{ _id: 0, TOTAL: 1 }_id es la excepción: se puede excluir en una proyección de inclusión.
Campos de un array{ "Movies.Title": 1 }Un array con solo los títulos: Movies: [ { Title: … }, … ]
④ Cursor

Ordenar, paginar y contar

mongosh
db.__COL__.find({ "contract.country": "Spain" })
  .sort({ TOTAL: -1, _id: 1 })   // TOTAL descendente; en empate, _id ascendente
  .skip(20)                      // saltar 2 páginas de 10
  .limit(10)                     // página de 10

db.__COL__.countDocuments({ "contract.country": "Spain" })   // contar
Desempates

Si dos documentos tienen el mismo valor en el campo de ordenación, su orden relativo no está garantizado. Añade un segundo criterio único (_id: 1) cuando el orden importe, por ejemplo al paginar.

¿count() o countDocuments()?

cursor.count() está obsoleto en mongosh (muestra un aviso). Usa db.col.countDocuments(filtro).

Resumen
